# Autonomous Colorist Invariants & Lumetri Rules

## 1. Zero-Blind-Grading Rule (Mandatory Virtual Scopes)
Never call `apply_lumetri_grade`, `set_lumetri`, or `set_effect_property` on a Lumetri Color component using guessed values. Before modifying any color parameter, you must inspect `@02_analysis/color_telemetry.json` generated by `@.agents/skills/balancing-primary-color-and-skins/scripts/virtual_scopes.py`.

## 2. The 3-Pass Grading Hierarchy (Separation of Concerns)
Never mix primary camera correction and stylized looks inside a single Lumetri instance on one clip:
- **Pass 1 (Clip-Level Primary Balance on V1/V2)**: Apply a base `Lumetri Color` effect on individual clips strictly to normalize exposure (Luma IRE `7` to `93`), neutralize RGB Parade grey-balance casts (`temp`/`tint`), and place skin tones on the Vectorscope I-Line (`55–70 IRE`).
- **Pass 2 (A-Roll to B-Roll Shot Matching on V2)**: Match B-roll clips on Track `V2` to the adjacent hero A-roll clip on Track `V1` using histogram percentile deltas before applying any global creative look.
- **Pass 3 (Sequence-Wide Creative Grade on Track V4 Adjustment Layer)**: Place the stylized aesthetic look (`@.agents/skills/applying-creative-lumetri-looks/references/lumetri-look-matrices.md` or extracted `style_dna.json` grade) on an Adjustment Layer on **Track V4** (or as a second stacked Lumetri instance) with `look_intensity` capped between `50` and `75`.

## 3. Broadcast & Skin-Tone Safety Limits
- **Black Floor**: Keep 1st-percentile Luma between `5.0` and `10.0 IRE` (except deliberate Moody Matte profiles capped at `14.0 IRE`). Never crush below `3.0 IRE`.
- **Highlight Ceiling**: Keep 99th-percentile Luma below `95.0 IRE`. If `p99_ire` exceeds `94.0`, `exposure` must not be positive; use negative `highlights` (`-15` to `-45`) and negative `whites`.
- **Skin-Tone Saturation Guardrail**: If `skin_detected` is `true` in `@02_analysis/color_telemetry.json` and global `saturation` is pushed above `112` or `temperature` is shifted beyond `±10`, verify via `export_frame` that facial skin has not clipped into orange/magenta.
